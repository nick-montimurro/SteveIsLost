# ✈️ Steve Is Lost: Euro-Trip Survival

Steve from Idaho accidentally boarded the wrong plane. Now he's stranded in Europe with no money, no phone, and zero language skills. Help him navigate through 6 countries and survive countless awkward conversations so he can finally make it home!

## 🎮 Play Online

You can play the game directly in your browser without installing anything!
👉 **[Play Steve Is Lost here](https://steveislost.vercel.app)**

---

## 🛠️ Run Locally

If you'd like to run the game on your own machine or tinker with the code, follow these steps:

**Prerequisites:** 
- [Node.js](https://nodejs.org/) installed on your machine.

1. **Clone the repository and navigate into it:**
   ```bash
   git clone https://github.com/nick-montimurro/SteveIsLost.git
   cd SteveIsLost
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Play the game:**
   Open your browser and navigate to the local host address provided in your terminal (usually `http://localhost:5173`).

## 💡 How to Play
- **Survive the Journey**: You must successfully navigate through 6 different European countries.
- **Branching Dialogue**: Choose your responses carefully! Your choices will result in Positive, Neutral, or Offensive reactions from the locals.
- **Manage Your Stats**: Keep an eye on your **HP**, **Hunger**, **Thirst**, and **Insanity**. If your HP drops to zero or your Insanity maxes out, it's Game Over!
- **Babel Fish**: Stuck in translation? Use your Babel Fish (🐟) to translate one dialogue option per interaction.
- **Level Up**: Earn XP by picking the best dialogue options to level up and increase your maximum stats.
